# Demirer Lab website

Source for **[demirerlab.github.io](https://demirerlab.github.io)**, the website of the Demirer Lab at Caltech.

- People: `_members/`
- Publications: `_data/sources.yaml` (citations are generated automatically from DOIs)
- News and photos: `_posts/` and `images/news/`
- Pages: `index.md`, `research/`, `team/`, `publications/`, `news/`, `open-positions/`, `contact/`, and others

See [CLAUDE.md](CLAUDE.md) for step-by-step instructions for common updates.
